# Abbreviations

Project abbreviations and acronyms used in identifiers and comments
(BARR-C:2018 rule 1.5.b). Add any new abbreviation here before using it.

| Abbreviation | Meaning |
|---|---|
| adc | Analog-to-digital converter |
| ao | Analog output (of an IR sensor module) |
| b_ | Prefix: Boolean variable |
| buf | Buffer |
| ch | ADC channel |
| clk | Clock |
| clkdiv | PWM clock divider |
| do | Digital output (of an IR sensor module) |
| g_ | Prefix: module-level (file-scope) variable |
| gpio | General-purpose input/output |
| hz | Hertz |
| idx | Index |
| ip | Internet Protocol address |
| isr | Interrupt service routine |
| kd / kp | Derivative / proportional gain of the steering controller |
| len | Length |
| m1 / m2 | Motor 1 (left wheel) / Motor 2 (right wheel), as labelled on the Robo Pico |
| mm | Millimetres |
| ms | Milliseconds |
| p_ | Prefix: pointer variable |
| pcb | lwIP protocol control block |
| pct | Percent |
| pos | Position |
| pwm | Pulse-width modulation |
| raw | Unprocessed ADC reading |
| rev | Revolution (of a wheel) |
| s | Seconds |
| ssid | Wi-Fi network name |
| sta | Wi-Fi station (client) mode |
| udp | User Datagram Protocol |
| um | Micrometres |
| us | Microseconds |
